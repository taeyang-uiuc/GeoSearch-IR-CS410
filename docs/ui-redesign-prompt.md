# GeoSearch-IR UI redesign prompt

Redesign the existing Flask and Leaflet restaurant search interface. Keep the map as the main surface and make search controls, ranked results, and saved searches easy to find. Keep the current search API, scores, map interactions, and browser storage format.

Use a light neutral canvas, white panels, forest green for navigation and primary actions, and warm coral for selected results. Set the interface in DM Sans with system fallbacks. Give the form, map, and results clear spacing and simple borders.

Show the map and results side by side on wide screens. At tablet widths, wrap the search controls. On phones, stack the search form, map, and results, keeping the map tall enough to use. Use labeled fields, keyboard-operable controls, visible focus, and a live status region. Keep Save State next to the saved search name field.

Verify that users can submit a query, inspect a map result, and save and restore a search. Check the layout at desktop and phone widths.
